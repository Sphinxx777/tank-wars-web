# Reference images and palettes

Decoded title previews and source palette exports used during research. These
files are not loaded by the browser game; the runtime uses
`dist/assets/title-indexed.bin` to animate the title palette.

`tools/extract-assets.py` regenerates the PNG previews from separately supplied
original resources. Provenance and licensing scope are recorded in
`THIRD_PARTY_NOTICES.md` at the repository root.
